description: "Connect a Confluence Cloud site with a scoped Atlassian API token and choose which spaces IrisAgent reads."

IrisAgent uses your Confluence pages to answer support tickets and chats.

## Before you start

- Your ticketing provider is already connected to IrisAgent.
- A Confluence Cloud site (address ends in `.atlassian.net`).
- An Atlassian user who can read the spaces you want IrisAgent to use. A dedicated service user is recommended (see [Permissions of the Atlassian Token](#permissions-of-the-atlassian-token)).

## Step 1: Create a scoped Atlassian API token

1. Signed in as that user, go to Atlassian account settings > **Security** > **API tokens** and create an API token with scopes ([Atlassian guide](https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/)).
2. Choose **Confluence** as the app and add these scopes:
   - `read:confluence-content.all`
   - `read:confluence-content.summary`
   - `read:confluence-space.summary`
   - `read:confluence-props`
   - `search:confluence`
3. Copy the token.

## Step 2: Find your Cloud ID

Open `https://{your-site-name}.atlassian.net/_edge/tenant_info`. Copy the `cloudId` value (a UUID). If you paste the whole line, IrisAgent extracts the UUID.

## Step 3: Connect Confluence in IrisAgent

1. In the [IrisAgent dashboard](https://web.irisagent.com/), go to **Data Sources** > **Knowledge Bases**.
2. On the Confluence card, click **Connect**.
3. Fill in:
   - **Confluence API Token**: from Step 1.
   - **Email Address**: the Atlassian user who created the token.
   - **Subdomain**: site name only. For `https://acme.atlassian.net`, enter `acme`.
   - **Cloud ID**: from Step 2.
4. Click **Connect**. The card shows **Connected** and the number of synced articles.

IrisAgent syncs pages and blog posts. Page labels become article tags, and edits are picked up on the next sync.

<Note>
  This card is for Confluence Cloud. For Atlassian Server or Data Center, use the **Atlassian/Jira Server** card under **Data Sources** > **Development**, or contact IrisAgent support.
</Note>

## Step 4: Choose spaces

1. On **Data Sources** > **Knowledge Bases**, click the settings gear on the Confluence card.
2. Under **Confluence Spaces**, select the spaces to include and click **Apply**. If none are selected, all spaces the token can read are included.

You can also limit access by giving the Atlassian user read access to only the relevant spaces.

## Step 5: Test it

Open **AI Products** > **Chatbot** and ask a question your Confluence pages answer. The Confluence page appears under **Sources**.

## Connection details

IrisAgent ingests Atlassian data from the last 3 months by default (configurable). It uses GET and POST API calls and stays within Atlassian rate limits. Call frequency is configurable.

### Permissions of the Atlassian Token

The token has the same access as the user who created it. Use a dedicated service user so you can grant or revoke access easily. To use only Confluence (not Jira), give that service user access to Confluence only, make sure it has the scopes above, and connect it as described in Step 3.

### Data governance and security

- Data is encrypted in transit and at rest, authenticated at each endpoint, and monitored for integrity.
- IrisAgent removes PII and does not store PII on its servers.
- You can limit the integration to specific projects and spaces.
- IrisAgent does not share data with third parties.
- IrisAgent is SOC 2 Type II and GDPR compliant.
