Connect Zoho Desk to import your tickets and knowledge base articles. IrisAgent uses them for suggested resolutions, SmartOps procedures (chat, voice, ticket auto-respond, and agent assist), AutoQA, AutoKB, and [Case Triggers](/deploying-irisagent/Tickets).

You connect with a Zoho OAuth client that you create. There is no Zoho marketplace app for this step.

## Step 1: Create a Zoho OAuth client

1. In the [Zoho Developer Console](https://accounts.zoho.com/developerconsole), click **Add Client**.
2. Select **Server Based Applications**.
3. On the **Client Details** tab, enter:
   - **Client Name:** `IrisAgent`
   - **Homepage URL:** `https://irisagent.com`
   - **Authorized Redirect URIs:** `https://frontend-api-server-v2.api.irisagent.com/v1/oauth/zoho/callback`
4. Click **Create**.
5. On the **Settings** tab, turn on **Use the same OAuth credentials for all data centers**.
6. On the **Client Secret** tab, copy the Client ID and Client Secret.

<Note>
  The redirect URI must match exactly, including `https` and `/v1/oauth/zoho/callback`. A mismatch is the most common reason the Zoho consent screen fails.
</Note>

## Step 2: Connect Zoho in IrisAgent

1. Sign in to the [IrisAgent dashboard](https://web.irisagent.com/) with Google, Microsoft, or Okta SSO.
2. Pick Zoho Desk:
   - **During onboarding:** on **Connect your first data source**, choose **Ticketing system**, then **Zoho Desk**.
   - **Later:** go to **Data Sources → Ticketing System** and pick **Zoho Desk**.
3. Paste the **Client ID** and **Client Secret**.
4. Click **Connect**, approve access in Zoho, and you return to the dashboard. Import starts automatically.

To change the connected Zoho user later, use the [Change Integration User](https://web.irisagent.com/manage-integration-user) page.

## What gets imported

- Tickets
- Knowledge base articles, from the same connection. See [Ticketing System KB](/data-sources/Ticketing-Provider-KB).

## Agent assist

There is no native Zoho Desk sidebar. Agents use suggested resolutions and procedures from the [IrisAgent dashboard](https://web.irisagent.com/). For a sidebar inside the ticket view, see the [Agent Copilot](/deploying-irisagent/Agent-Copilot) apps for Zendesk, Salesforce, Intercom, Freshworks, and Jira.
