## Overview

The Shopify integration lets an existing IrisAgent chatbot answer questions using live Shopify data. Connecting the data does not require you to publish the chatbot on the Shopify storefront. You can keep using the chatbot on any website where it is already deployed.

The integration supports:

- Answering live product, pricing, inventory, and availability questions
- Looking up order status and shipment tracking after matching an order number and email address
- Associating one existing IrisAgent chatbot with the Shopify connection
- Optionally adding that chatbot to the Shopify storefront with the IrisAgent app embed
- Changing the associated chatbot or disconnecting the store later

<Note>
  Product and order information is read live from Shopify and is not synchronized into the IrisAgent knowledge base. Refunds, cancellations, returns, and other write actions are not included.
</Note>

## Before you begin

You need:

- IrisAgent administrator access
- Shopify administrator access for the store
- At least one chatbot configured in IrisAgent
- The permanent `*.myshopify.com` domain for the store

## Connect Shopify data from IrisAgent

1. Log in to the [IrisAgent dashboard](https://web.irisagent.com/).
2. In the left navigation, open **Data Sources → E-commerce**.
3. Select the **Shopify** card.
4. Enter the permanent Shopify domain, such as `your-store.myshopify.com`.
5. Choose the IrisAgent chatbot that should use the Shopify data.
6. Click **Connect Shopify data**.
7. Sign in to Shopify as a store administrator and approve the requested read-only permissions.

After authorization, Shopify returns you to IrisAgent. The configuration page shows the connected store and granted permissions. The selected IrisAgent chatbot can now answer supported commerce questions wherever that chatbot is deployed.

## Start from Shopify

Merchants can also begin by installing IrisAgent from Shopify:

1. Install IrisAgent and approve the requested read-only permissions in Shopify.
2. Sign in to IrisAgent when redirected.
3. Choose the chatbot that should use the Shopify data.
4. Click **Finish Shopify setup**.

Both connection methods provide the same live product and order capabilities.

## Configure commerce capabilities

After connecting the store, use **Read-only commerce capabilities** on the Shopify configuration page to enable or disable:

- **Product search, pricing, and inventory availability**
- **Order status and shipment tracking**

These capabilities apply only to the chatbot selected under **Chatbot using this store's data**.

For product questions, the chatbot searches current Shopify product data and returns up to five matching products. For order questions, the chatbot collects both the order number and the email used on the order. IrisAgent returns order details only when both values match the same Shopify order.

Shopify's standard `read_orders` permission covers orders from the most recent 60 days. Access to older orders requires Shopify's separately approved `read_all_orders` permission, which this integration does not request by default.

## Optionally add the chatbot to the storefront

Connecting Shopify data does not automatically publish the chatbot on the storefront. If you want the chatbot to appear there:

1. Open **Data Sources → E-commerce → Shopify** in IrisAgent.
2. Click **Enable chatbot in Shopify**.
3. In the Shopify theme editor, open **App embeds** if it is not already visible.
4. Turn on **IrisAgent Chatbot**.
5. Click **Save**.
6. Open the storefront and confirm that the chat widget appears.

The app embed loads the same chatbot selected on the Shopify configuration page. Its appearance and behavior continue to come from the chatbot configuration in IrisAgent.

## Change the chatbot

To use a different chatbot with the connected store:

1. Open **Data Sources → E-commerce → Shopify** in IrisAgent.
2. Select another option under **Chatbot using this store's data**.

The new selection receives Shopify data capabilities. If the IrisAgent app embed is enabled, the storefront also uses the newly selected chatbot without a theme-code change. Only IrisAgent administrators can change the Shopify association.

## Disconnect Shopify

1. Open **Data Sources → E-commerce → Shopify**.
2. Click **Disconnect** and confirm the action.

Disconnecting removes IrisAgent's access to Shopify data. To remove the widget from the storefront as well, disable **IrisAgent Chatbot** under **Online Store → Themes → Customize → App embeds**, or uninstall the IrisAgent app in Shopify.

## Troubleshooting

### The chatbot cannot answer Shopify questions

- Confirm that the Shopify configuration page shows the store as connected.
- Confirm that the relevant read-only commerce capability is enabled.
- Confirm that the chatbot being tested is the one selected for the store.
- If IrisAgent shows **Reconnect Shopify**, reconnect and approve the requested permissions.

### The storefront chatbot does not appear

- Confirm that **IrisAgent Chatbot** is enabled under **Online Store → Themes → Customize → App embeds**.
- Click **Save** in the theme editor.
- Confirm that you edited the published theme.
- Test the published storefront in a new browser tab.

### The Connect Shopify data button is disabled

- Confirm that you are an IrisAgent administrator.
- Enter the permanent `*.myshopify.com` domain, not a custom storefront domain.
- Select a chatbot.
- If the page says Shopify is not configured for the environment, contact IrisAgent support.

### Shopify reports that the store is already connected

A Shopify store can belong to only one IrisAgent account. Disconnect it from the original IrisAgent account or contact IrisAgent support before connecting it elsewhere.

## Permissions and customer data

The integration requests the Shopify permissions displayed during authorization. IrisAgent stores the shop connection, capability settings, and encrypted Shopify credentials. Product and order information is requested from Shopify only when the chatbot needs it. IrisAgent does not synchronize Shopify customer profiles or order history into the IrisAgent knowledge base.
