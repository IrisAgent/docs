---
title: "Shopify"
description: "Connect live Shopify product and order data to an IrisAgent chatbot"
---

Connect Shopify so an existing IrisAgent chatbot can answer with live store data. You do not have to publish the chatbot on your storefront. It keeps working wherever it is already deployed.

The chatbot can:

- Answer product, pricing, inventory and availability questions
- Look up order status and shipment tracking, after matching the order number and email

<Note>
Data is read live from Shopify and is not synced into the IrisAgent knowledge base. Refunds, cancellations, returns and other write actions are not supported.
</Note>

## Before you begin

- IrisAgent administrator access
- Shopify administrator access (or staff permission to install apps)
- At least one chatbot in IrisAgent
- Your store's permanent `*.myshopify.com` domain

## Install with a private install link

1. Email [IrisAgent support](mailto:support@irisagent.com) with your permanent `*.myshopify.com` domain. Support sends you a private install link for your store.
2. Sign in to IrisAgent, then open the link in the same browser.
3. In Shopify, click **Install** and approve the read-only permissions.
4. Back in IrisAgent (**Data Sources → E-commerce → Shopify**), choose the chatbot under **Chatbot using this store's data**.
5. Click **Finish Shopify setup**.

The page now shows your store as connected.

<Note>
A private install link works only for its store and expires after about seven days. Ask support for a new one if it expires.
</Note>

### Start from Shopify

If you install IrisAgent from Shopify instead, approve the permissions, sign in to IrisAgent when redirected, choose the chatbot and click **Finish Shopify setup**. The result is the same.

## Choose capabilities

On the Shopify page, under **Read-only commerce capabilities**, turn on or off:

- **Product search, pricing, and inventory availability:** returns up to five matching products.
- **Order status and shipment tracking:** the chatbot asks for the order number and order email, and returns details only if both match the same order.

Capabilities apply only to the chatbot selected under **Chatbot using this store's data**. Change the selection at any time to switch chatbots (administrators only).

Shopify's standard `read_orders` permission covers the last 60 days of orders. Older orders need Shopify's separately approved `read_all_orders` permission, which this integration does not request by default.

## Add the chatbot to your storefront (optional)

1. On the Shopify page in IrisAgent, click **Enable chatbot in Shopify** to open the theme editor.
2. Under **App embeds**, turn on **IrisAgent Chatbot**.
3. Click **Save**, then check the chat widget on your storefront.

The widget uses the chatbot selected in IrisAgent, with its existing appearance and behavior. If you switch chatbots, the storefront updates without theme changes.

## Disconnect

On the Shopify page, click **Disconnect** and confirm. This removes IrisAgent's Shopify credentials and the storefront widget stops loading. Uninstall the IrisAgent app separately in Shopify Admin.

## Troubleshooting

**The chatbot cannot answer Shopify questions.**
- Check the store shows as connected and the right capability is on.
- Make sure you are testing the chatbot selected for the store.
- If you see **Reconnect Shopify**, click it and approve the new permissions.

**The storefront widget does not appear.**
- Confirm **IrisAgent Chatbot** is on under **Online Store → Themes → Customize → App embeds**, and that you clicked **Save**.
- Make sure you edited the published theme, then test in a new tab.

**Finish Shopify setup is disabled or fails.**
- You must be an IrisAgent administrator and select a chatbot.
- Sign in to the correct IrisAgent account.
- If the setup link expired, open IrisAgent from **Shopify Admin → Apps** to restart, then finish setup.
- If the page says Shopify is not configured for this environment, contact support.

**Shopify says "This app is under review".** The public app is awaiting Shopify App Store approval. Ask support for a [private install link](#install-with-a-private-install-link).

**Shopify says the store is already connected.** A store can belong to only one IrisAgent account. Disconnect it from the other account or contact support.

## Permissions and data

IrisAgent requests the read-only permissions shown during authorization. It stores the shop connection, capability settings and encrypted Shopify credentials. Product and order data is fetched only when the chatbot needs it. Customer profiles and order history are not synced into IrisAgent.
