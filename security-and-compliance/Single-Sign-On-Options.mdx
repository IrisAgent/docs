IrisAgent does not require or host login credentials. You sign in through Google, Microsoft, Salesforce, or Okta. The scopes each one requests are below.

## Google SSO

Uses [Google OAuth2 APIs](https://developers.google.com/identity/protocols/oauth2/scopes#oauth2):

- `userinfo.email`: your primary Google Account email address
- `userinfo.profile`: your personal info, including any you've made public

## Salesforce SSO

For customers using Salesforce Service as their main ticketing system. Uses [Salesforce OAuth APIs](https://help.salesforce.com/s/articleView?id=sf.remoteaccess_oauth_tokens_scopes.htm&type=5):

- `api`: access the signed-in user's account through APIs such as REST API and Bulk API 2.0
- `refresh_token`: generate refresh tokens

## Microsoft (Azure Active Directory) SSO

Uses [Azure OAuth APIs](https://learn.microsoft.com/en-us/azure/active-directory/develop/scopes-oidc):

- `user.read`: basic user info
- `openid`: get tokens for authentication
- `profile`: given name, surname, and preferred username
- `email`: primary email address

## Okta SSO

Uses [Okta OpenID Connect and OAuth APIs](https://developer.okta.com/docs/api/oauth2/):

- `openid`: OpenID Connect
- `email`: the user's email claims
- `profile`: the user's default profile information

For SAML setup, see [Okta SSO](/security-and-compliance/Okta-SSO).
