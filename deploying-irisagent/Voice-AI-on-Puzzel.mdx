## Overview

The IrisAgent Call Summary widget runs inside the Puzzel Agent Application. After each call, it shows an AI summary (customer issue, key points, resolution, and a suggested wrap-up note) that agents copy into Puzzel's wrap-up fields with one click.

This guide covers the **v1 (post-call summary)** integration:

1. The widget loads as an iframe in the Puzzel agent desktop and listens for the `call.ended` event through the Puzzel Widget API.
2. When a call ends, it sends the call ID and agent context to IrisAgent over an authenticated websocket.
3. IrisAgent fetches the recording from the Puzzel Archive through the Puzzel Agent Web Services (PAWS) REST API, then transcribes and summarizes it.
4. The summary appears in the widget, usually within a few seconds. The agent clicks **Copy to wrap-up**.

## Prerequisites

- A Puzzel Contact Centre tenant with admin access to the **Administration Portal**
- Permission to add widgets in **Administration → Widgets → Widget Administration**
- Recording enabled on the queues you want summarized
- An IrisAgent account with **Voice AI** enabled. Ask your IrisAgent representative to enable it.

## Step 1: Sign up for IrisAgent

Sign up by connecting your ticketing platform or a public website as a knowledge source. Then ask your IrisAgent representative to enable **Voice AI** and the Puzzel integration. They will give you a **Tenant ID** and a **Widget API Key** for Step 3.

## Step 2: Create a PAWS service account in Puzzel

IrisAgent needs read access to the Puzzel Archive to fetch recordings.

1. Sign in to the [Puzzel Administration Portal](https://admin.puzzel.com).
2. Go to **Users → Administrators** and create an administrator for the integration (for example `irisagent-integration`). A dedicated account lets you audit IrisAgent's activity separately.
3. Grant these permissions:
   - **Archive:** read access to recordings and call metadata
   - **Real-time:** read access to queue and call information
4. Generate API credentials and note the **Customer Number**, **Username**, and **Password**.
5. Share these credentials with your IrisAgent representative through the secure channel they provide.

## Step 3: Add the widget in Puzzel

1. In the Puzzel Administration Portal, go to **Widgets → Widget Administration** and click **Add Widget**.
2. Configure it:
   - **Name:** `IrisAgent Call Summary`
   - **URL:** `https://widgets.irisagent.com/puzzel/summary`
   - **Tab title:** `AI Summary`
   - **Default tab:** Off (the widget activates when a call ends)
3. Add these **Widget Properties**:

| Property name     | Type     | Value                       |
| ----------------- | -------- | --------------------------- |
| `irisTenantId`    | String   | Your Tenant ID              |
| `irisApiKey`      | Password | Your Widget API Key         |
| `irisEnvironment` | Dropdown | `production`                |

4. Under **Feature Policy**, allow `clipboard-write` (needed for **Copy to wrap-up**).
5. Save the widget.

## Step 4: Assign the widget to agents

1. Go to **Widgets → Widget Configuration**.
2. Select the agent user groups that should see the widget.
3. Enable **IrisAgent Call Summary** for those groups and save.

## Step 5: Customize the summary (optional)

By default, summaries include **Customer issue**, **Key points discussed**, **Resolution**, and **Wrap-up note**. To change the sections (for example, to add sentiment, product name, or an escalation flag), ask your IrisAgent representative.

## Step 6: Test the integration

1. Sign in to the Puzzel Agent Application as a test agent and confirm the **AI Summary** tab appears.
2. Place a test call into a recorded queue, answer it, and end it.
3. Within a few seconds, the **AI Summary** tab should show the summary.
4. Click **Copy to wrap-up** and check that the summary appears in Puzzel's wrap-up fields.

If no summary appears:

- Check that recording is enabled on the test queue.
- Open the browser console in the agent application and look for `[IrisAgent]` messages.
- Contact `support@irisagent.com` with the call ID.
