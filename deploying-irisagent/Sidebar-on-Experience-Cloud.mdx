Run the IrisAgent Sidebar (suggested resolutions, similar cases, sentiment, summaries and Jira actions) on a Case record page in an **Experience Cloud site**, such as an Employee Community.

<Note>
The sidebar is for people **working** cases. To deflect cases before they are created, use the [Case Deflector](/deploying-irisagent/Case-Deflector-on-Salesforce).
</Note>

## Prerequisites

- Admin access to a Salesforce org with an Experience Cloud site
- The IrisAgent Salesforce package (first install: see the [Salesforce data source guide](/data-sources/Salesforce))
- Access to the IrisAgent dashboard

The sidebar needs a saved Case, so it only works on a **Case record page**. It does not work on a case creation, Contact Support or Home page.

## 1. Install or upgrade the package

Experience Cloud support requires **IrisAgent Sidebar v1.4.0** or later. Log in to the target org and install **v1.5.0** over your current version:

- **Production or Developer org:** [Production installation link](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tak000000pGfRAAU)
- **Sandbox org:** [Sandbox installation link](https://test.salesforce.com/packaging/installPackage.apexp?p0=04tak000000pGfRAAU)

Choose **Install for All Users**. This one package includes the sidebar, the Experience Cloud sidebar and the Case Deflector.

## 2. Grant member permissions

The sidebar runs as your site's **authenticated members**.

1. In **Setup**, go to **Users → Permission Sets** and open **IrisAgent Sidebar Community**.
2. Click **Manage Assignments → Add Assignment**, select the members (or use a permission set group on their profile) and click **Assign**.

Members also need, through your own profile and sharing settings:

- **Case read access.** The sidebar reads Subject, Status, Priority, Case Number, Description and Account Name.
- **Knowledge read access** (`Knowledge__kav`), optional. Without it, article previews show only a title and link. Answers are not affected.

Confirm the Remote Site Setting for `https://frontend-api-server-v2.api.irisagent.com` is active under **Setup → Remote Site Settings**. No browser CSP change is needed for the API.

## 3. Check the site security level

If the sidebar is missing from the Components panel, or you see "components are blocked due to the site's security level setting":

1. In **Experience Builder**, go to **Settings → Security & Privacy**.
2. Choose a level that allows custom components (usually **Relaxed CSP**).
3. Publish the site.

## 4. Add the sidebar to the Case record page

1. In **Setup**, go to **Digital Experiences → All Sites** and click **Builder** for your site.
2. Open the **Case** record page.
3. Drag **IrisAgent Sidebar (Experience Cloud)** from the **Components** panel onto the page, usually a right-hand column.
4. Keep **Record Id** set to `{!recordId}`. If it is blank, the sidebar shows "No record ID available."
5. Click **Publish**.

## 5. Verify

1. Open the live site as a member with the permission set (not as an admin previewing in Builder).
2. Open a Case that IrisAgent has processed.
3. Check that suggested resolution, similar cases, sentiment and summary load, and that links open.

Two differences from the internal console: links open in the same tab, and article previews may show only a title and link.

## Troubleshooting

**Not in the Components panel:** confirm package version 1.4.0 or later, check the site security level, and make sure you are on a Case record page.

**"No record ID available":** set **Record Id** to `{!recordId}` and confirm the page is a Case record page.

**Error or no data:** confirm the member has **IrisAgent Sidebar Community**, can open the same Case directly, and that the Remote Site Setting is active.
