## Prerequisites

- An 8x8 account with admin access to the 8x8 Admin Console
- An 8x8 phone number or extension that receives customer calls
- A license assigned to that extension (call forwarding rules need one)
- An IrisAgent account, connected to your ticketing platform or using your public website as the knowledge source
- The external phone number provided by the IrisAgent team

## Step 1: Forward calls to IrisAgent

1. Sign in to the [8x8 Admin Console](https://admin.8x8.com) and go to **Users**.
2. Click **Edit** (pencil icon) next to the extension, then select **Call forwarding rules**.
3. Click **Edit** next to the **Forward all calls** rule to enable it.
4. Select **Selected Users or External Numbers**.
5. Enter the IrisAgent phone number with the full country code (for example, +1 for US numbers) and click **Add to the List**.
6. Set how many seconds to ring before moving on, and choose **Sequentially** or **Simultaneously**.
7. Click **Save** for the rule, then **Save** again for the user profile.

### Optional: forward only at certain times

To use Voice AI only during set hours (for example, after hours), create a custom rule instead:

1. In **Call forwarding rules**, click **Add New Rule** and name it (for example, "IrisAgent Voice AI").
2. Under **When to Apply this Rule**, select **Recurring Schedule** and set the days and times.
3. Under **Forward Calls to**, select **Selected Users or External Numbers**, enter the IrisAgent number, and click **Add to the List**.
4. Save the rule, then save the user profile.

## Step 2: Test

1. Call your number from an external phone (not an 8x8 line).
2. Confirm you hear the IrisAgent Voice AI greeting.
3. Ask a few common questions and check the answers.
